# 🎨 NIEK HENDRIX - Kunstenaar Portfolio

Een professioneel WordPress-portfolio van schilderijen en kunstwerk van **NIEK HENDRIX**. Deze website showcases het werk en de carrière van de kunstenaar met een mooie galerij-layout en informatieve secties.

## 📋 Over het Project

Dit is een volledig WordPress-gebaseerde website voor een professionele kunstenaar, gebouwd met:
- **PHP** (66.9%)
- **JavaScript** (16.9%)
- **CSS** (15.3%)
- **Vue** (0.4%)

## 🚀 Functies

### Pagina's & Secties
- **🖼️ Paintings** - Galerij van alle kunstwerken
- **📖 Biography** - Levensverhaal en carrière van de kunstenaar
- **📸 Media** - Foto's en video's
- **🤝 Art Dealer** - Informatie voor galeriehouders en collectors
- **✍️ Artist Statement** - Verklaring van artistieke visie
- **📱 Instagram** - Directe link naar social media
- **📧 Contact us** - Contactformulier en contactgegevens

### Archief
- Werken georganiseerd per jaar (2014-2024)
- Makkelijk navigeerbaar portfolio
